# 算術課題の修正と固定テスト（#23・#25）

[開発手順](development.md)で依存を導入し、`ANTHROPIC_API_KEY`を環境変数に設定します。
実行すると有料APIを呼びます。既定モデルは`claude-haiku-5-5`です。

```bash
python -m coding_agent.client_repair
LLM_MODEL=claude-sonnet-5-5 python -m coding_agent.client_repair
```

成功時は修正前後のテスト状態と`calculator.py`のunified diffを表示します。一時ディレクトリは終了時に削除します。

## 教材と処理の対応

公式Client SDKの[ツール利用例](https://github.com/anthropics/anthropic-sdk-python/blob/main/examples/tools.py)
と同じく、`messages.create()`にツール定義を渡し、assistant応答全体と、対応する
`tool_use_id`付きの結果を履歴に追加します。教材の本文は2026-11-11に確認しました。

1. アプリが初期ソースと固定テストを生成し、減算を返す初期実装のテストが失敗することを確認します。
2. モデルが`Read`・`Edit`・`run_tests`から操作を選び、アプリが範囲を検証して実行します。
3. アプリは固定テストの終了コードと出力を返します。失敗した場合、モデルは上限内で再修正・再テストできます。
4. モデルの正常終了後、アプリは最終ソースに対するモデルのテスト成功を確認し、自身でもう一度テストします。

アプリが操作の許可、履歴、反復上限、完了判定を持つ構成は [ADR 0007](adr/0007-manual-client-sdk.md) を参照してください。

## 操作境界と初期値

| 項目 | 今回の範囲 |
| --- | --- |
| 作業場所 | アプリが新規生成する一時ディレクトリ。既存プロジェクトのパスは受け取らない |
| Read | `calculator.py`と`test_calculator.py`のみ。外部パス、`..`、リンクを拒否 |
| Edit | `calculator.py`の一意な文字列置換のみ。新規作成、テスト編集、全件置換を拒否 |
| 実行可能な修正 | `def add(a, b)`が`a + b`・`a - b`・`a * b`のいずれかを返すだけ。UTF-8で4096バイト以内 |
| 構文検査 | 実ファイルのバイト列からASTを作り、許可した3つの構文木と比較。import・呼出し・ループ・デコレーター・既定引数等は実行前に拒否 |
| `run_tests` | 引数なし。モデルから最大4回。実行直前にも関数の構文とテスト本文の不変を確認 |
| 固定テスト | 標準ライブラリunittestの4件（正数・異符号・ゼロ・負数）。モデルは変更不可 |
| テストプロセス | 現在のPythonで`-I -B test_calculator.py`を実行。shellなし、環境変数の引継ぎなし、5秒で打切り |
| API要求 | `max_steps`は1〜20、既定12。最終回答も1回と数える。要求ごとに4096出力トークン、timeout 30秒、再試行0 |

作業ディレクトリはアプリ所有で、外部プロセスが同時に編集しない前提です。
構文検査の対象はこの算術課題です。実行全体の時間・費用の上限は設けていません。

## 停止と検証の範囲

範囲外の操作やテスト実行の例外は、固定文言のエラー結果で返します。API異常や想定外の
内部エラーで停止します。テスト未実行、古い結果、失敗した結果では成功扱いにしません。

[手動ループのテスト](../tests/test_client_repair.py)は、実SDKと模擬応答を使い、
誤修正、固定テストの失敗、再修正、再テスト、対象外操作、成功判定と停止を確認します。
[算術課題のテスト](../tests/test_repair_exercise.py)は、許可構文、固定テストの改変・リンクの拒否、
テストプロセスの環境とタイムアウトを確認します。通常テストはAPIキー・外部通信なしで動きます。
実モデルの課題達成や費用は模擬応答では検証できません。
